# Grant Risk Estimator

The code line of the thesis *„Mesterséges intelligencián alapuló rendszer fejlesztése pályázati felhívások automatikus feldolgozására, kategorizálására és kockázati értékelésére"*. It labels Hungarian grant calls with a rule-based risk level, and it compares machine-learning models that predict that level from the raw text.

**Status:** skeleton. The stages are specified but not implemented yet; every command reports "not implemented yet".

## Stages

| Command | Stage | What it does |
|---|---|---|
| `acquire` | C1 | Build the corpus: one PDF per call, from the frozen snapshot. |
| `convert` | C2 | Convert each PDF to Markdown, locally. |
| `extract` | L1 | Extract the 10 factor values: expert import, regex, LLM. |
| `consolidate` | L2 | Choose one value per factor. |
| `label` | L3 | Points, imputation, total score, fixed and tercile labels. |
| `represent` | M1 | TF-IDF and transformer embeddings of the full text. |
| `train` | M2 | Repeated stratified cross-validation of the classifiers. |
| `validate` | E1 | Compare the extractors with the expert's gold points. |
| `evaluate` | E2 | Model metrics, error sizes, comparison table. |
| `report` | E3 | Dashboard, per-document risk dataset, thesis tables. |
| `run-all` | | Every stage in order. |

```
python -m grantrisk --help
python -m grantrisk <command> [--config FILE]
```

This needs the package installed (see Setup). Without installing it, put the source folder on the path first: `set PYTHONPATH=src` (Windows) or `PYTHONPATH=src python -m grantrisk …`.

## Setup

Python 3.11 or later.

```
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -e ".[dev]"
python -m pytest
```

The tests also run without installing the package: `python -m pytest` from this folder (the source folder is on pytest's path).

## Configuration, data and secrets

- **Configuration:** `config/default.yaml`. Every path, threshold and parameter is set there (ARC-03). Another file can be selected with `--config` or the `GRANTRISK_CONFIG` environment variable.
- **Data:** everything the pipeline produces lives under the data root (`data/` by default), which is not under version control. The inputs from the old code line are read-only.
- **Secrets:** API keys come from environment variables; copy `.env.example` to `.env`. `.env` is never committed.

## Layout

```
config/          configuration
prompts/         LLM prompt versions (P5 is the current one)
src/grantrisk/   the package: one sub-package per group of stages
tests/           tests and fixtures (the gold set)
tools/           helper scripts (coverage of the specification)
```
